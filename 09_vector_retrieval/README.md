# N GPU 向量检索引擎

## 简介

凭借你 InfiniTensor 训练营的经历和人工智能与并行计算方面的出色成绩，你加入了一家大模型应用基础设施团队。团队正在建设面向 RAG、推荐系统和多模态检索的向量数据库服务。每一次用户查询都会被编码成高维向量，并需要在数百万到数千万条候选向量中找出最相似的 Top-K 结果。

CPU 实现虽然容易开发，但在高并发、低延迟场景下很快遇到瓶颈。GPU 有强大的并行计算和内存带宽，但向量检索并不是简单地写一个距离计算 kernel：你需要考虑数据布局、索引结构、Top-K 归并、批处理大小、显存容量、召回率和延迟之间的权衡。你的任务是开发一个 GPU 加速的向量检索引擎，并用实验说明自己的系统设计取舍。

## 任务内容
开发一个 CUDA 程序，实现一个简化但完整的 GPU 向量检索引擎。
