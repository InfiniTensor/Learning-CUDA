# v8 方向8：ILP与循环展开

基础版本：已晋级的`v7_branch_reduction`。本版本为最终晋级版本。

将E4M3固定7步、E2M1固定3步二分循环由`#pragma unroll 1`改为完全展开，使比较链直接进入指令流，去掉循环控制，并给编译器更多指令调度空间。其他代码不变。

| 场景 | v7量化 ms | v8量化 ms | 吞吐提升 |
|---|---:|---:|---:|
| MXFP8 block | 5.489136 | 5.458944 | +0.55% |
| MXFP8 tensor | 11.059200 | 10.679184 | +3.56% |
| NVFP4 block | 1.509376 | 1.445888 | +4.39% |
| NVFP4 tensor | 8.155536 | 7.859648 | +3.76% |

测试为预热10次、计时50次、交错5轮取median中位数；四场景几何平均吞吐提升约3.06%。四个完整流程的权重文件和反量化输出均与v7逐字节一致。
