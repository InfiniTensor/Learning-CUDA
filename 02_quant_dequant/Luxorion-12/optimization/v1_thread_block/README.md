# v1 方向1：Thread / Block配置

目标：保持量化数据分块和数值语义不变，只扫描反量化CUDA threads-per-block。候选值为64、128、256和512；量化kernel的32线程MXFP8块、16线程NVFP4块暂不改变。

选择规则：多轮比较kernel median；综合结果优于v0、核心用例没有实测回退且正确性不变，即晋升为下一方向的基线。

## 结论

方向1已晋级，后续方向从本版本的128线程配置开始。

- 128线程相对256线程的四场景几何平均提升约0.57%，四个核心场景均未回退。
- 512线程几何平均回退约2.44%。
- 64线程在初筛中明显更慢，因此未进入高精度复测。
- 三个高精度候选在四种权重文件上的反量化输出SHA-256完全一致。
- 完整回归测试13/13通过。

详细测量见`results.md`。本目录保留可通过`LUX_DEQUANT_THREADS`编译定义复现实验的源码；默认值为获选的128。
