# v7 方向7：分支与搜索路径优化

基础版本：`v6_bank_conflict`。本版本已晋级。

## 修改

- E4M3编码的有序码值定位由最多126次线性扫描改为固定7步二分查找。
- E2M1由最多7次线性扫描改为固定3步二分查找。
- 最近值、ties-to-even、随机舍入、饱和及符号处理均保持原语义。
- 本方向用`#pragma unroll 1`明确禁止展开，循环展开单独留给方向8评估。

## 性能

| 场景 | v6量化 ms | v7量化 ms | 加速比 |
|---|---:|---:|---:|
| MXFP8 block | 12.313088 | 5.476304 | 2.25x |
| MXFP8 tensor | 113.155968 | 11.034080 | 10.25x |
| NVFP4 block | 8.879552 | 1.509376 | 5.88x |
| NVFP4 tensor | 9.482240 | 8.135680 | 1.17x |

测试为预热5次、计时20次、交错3轮取median中位数。四场景全部更快，综合几何平均约3.55x。

## 正确性

四个完整流程的`weights.luxq`和`restored.tensor.bin`均与此前最佳版本逐字节一致，覆盖nearest、stochastic、FP32/FP16输入和FP32/FP16/BF16输出。
