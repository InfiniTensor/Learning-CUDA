# v3 方向3：向量化内存访问

基础版本：`v1_thread_block`（方向2没有代码晋级）。本版本已晋级。

## 修改

- MXFP8反量化由每线程处理1个code改为一次32-bit加载4个连续code。
- NVFP4反量化由相邻两线程重复读取同一packed byte，改为每线程读取1 byte并恢复2个元素。
- FP32使用`float2`、FP16使用`half2`、BF16使用`bfloat162`成对写回。
- 非4倍数/奇数长度使用有界标量尾部路径。
- 保留NVFP4原有浮点乘法顺序，避免结合律改写造成末位舍入变化。

## 性能

每个进程预热20次、计时200次，v1/v3交错运行7轮，取7轮median的中位数。

| 场景 | v1 ms | v3 ms | 吞吐提升 |
|---|---:|---:|---:|
| MXFP8 block / FP32输出 | 0.059392 | 0.037728 | 57.43% |
| MXFP8 tensor / BF16输出 | 0.047104 | 0.028672 | 64.29% |
| NVFP4 block / FP32输出 | 0.051200 | 0.037216 | 37.58% |
| NVFP4 tensor / FP16输出 | 0.047104 | 0.030464 | 54.62% |

四场景几何平均吞吐提升约53.1%，且没有单项回退，因此晋级为方向4的基础。
