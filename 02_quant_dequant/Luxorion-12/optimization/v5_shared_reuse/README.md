# v5 方向5：共享内存复用

基础版本：`v3_vectorized_memory`。本版本未晋级。

候选把每个CUDA block需要的16个scale预取并解码到共享内存；tensor-scale只加载一次。四类输出均与v3逐字节一致。

| 场景 | v3 ms | v5 ms | 结果 |
|---|---:|---:|---:|
| MXFP8 block | 0.037616 | 0.037808 | -0.51% |
| MXFP8 tensor | 0.028672 | 0.028416 | +0.90% |
| NVFP4 block | 0.037600 | 0.044032 | -14.61%（按v5耗时） |
| NVFP4 tensor | 0.030400 | 0.029696 | +2.37% |

测试为预热20次、计时200次、交错7轮取中位数。NVFP4 block的同步成本造成明显回退，因此不晋级；方向6继续基于v3。
