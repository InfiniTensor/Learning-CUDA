# 金融衍生品定价与风险估计

## 简介

鉴于你有 InfiniTensor 训练营的经历，并且在人工智能与并行计算方面的成绩出众，你被一家量化交易公司邀请加入高性能计算团队。公司每天需要为大量复杂衍生品重新估值，以控制风险敞口和交易保证金。传统 CPU 实现虽然精度可靠，但面对数千万条随机路径和多种路径依赖期权时，计算速度无法满足实时风控需求。

你注意到，期权路径之间基本相互独立，非常适合 GPU 并行。你的任务是开发一个 CUDA 加速的衍生品定价程序，使其能够在普通 GPU 上快速计算欧式期权、亚式期权或障碍期权等合约的价格，并输出可解释的误差或收敛指标。

## 任务内容
开发一个 CUDA 程序，实现衍生品定价与风险指标估计。
