# 实时图像非局部均值降噪

## 简介

鉴于你有 InfiniTensor 训练营的经历，并且在人工智能与并行计算方面的成绩出众，你被邀请加入 “巡天” 深空探测影像团队。探测器正在一颗远日小行星的背光面低空飞行，机载相机只能在极低照度和短曝光时间下拍摄。传回的画面充满随机噪声和传感器热噪声，而这些画面将直接用于地形重建、着陆点筛选和异常目标识别。

任务窗口非常短，探测器不能等待地面慢速处理后再调整姿态。普通均值滤波会抹掉陨石坑边缘和细小裂隙，过强的局部滤波又会保留大量颗粒噪声。你需要在机载 GPU 上实现一个实时图像降噪模块，在尽量保留纹理和边缘的同时抑制噪声，并给出图像质量与处理延迟之间的权衡分析。

## 任务内容
开发一个 CUDA 程序，实现灰度图或 RGB 图像的非局部均值降噪。
