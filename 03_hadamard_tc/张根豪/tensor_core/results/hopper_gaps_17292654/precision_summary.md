# PTX split 精度改进实测

实际 Dao v1.1.0，全张量 native 最大绝对误差；FP16 <0.01，BF16 <0.05。
每组核心矩阵为108配置，不能与包含D512/1024的132配置分母混用。
p0 原算法；p1 高低部分独立累加；p2 再增加一层 native 残差。
